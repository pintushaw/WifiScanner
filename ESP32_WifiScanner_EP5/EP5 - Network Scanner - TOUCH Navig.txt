| TFT Touch Pin | Function          |
| ------------- | ----------------- |
| `T_IRQ`       | Touch interrupt   |
| `T_DO`        | Touch SPI MISO    |
| `T_DIN`       | Touch SPI MOSI    |
| `T_CS`        | Touch chip select |
| `T_CLK`       | Touch SPI clock   |



Touch Pins - ESP32 Pin
-----------------------

T_DO  ------  GPIO16
T_DIN ------  GPIO17
T_CLK ------  GPIO32
T_CS  ------  GPIO25
